# Genesis package installation

Choose the guide for the platform where you want to install a built Genesis package:

- [Grav](grav/README.md)
- [Joomla](joomla/README.md)
- [WordPress](wordpress/README.md)
- [phpBB](phpbb/README.md)

The package ZIP files are created in the repository's `dist` directory. Do not rename or rearrange folders inside the archives before installation.
